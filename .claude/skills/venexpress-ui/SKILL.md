# Venexpress UI Design System

This skill defines how Claude should design and improve Venexpress interfaces.

The goal is NOT simply to make interfaces "pretty".

The goal is to create interfaces that feel:

- professional
- intentional
- modern
- distinctive
- trustworthy
- production-ready
- coherent with a real logistics company

Avoid generic AI-generated SaaS aesthetics.

---

# Core Design Philosophy

Venexpress should look like a real logistics company product,
not like a generic dashboard template generated by AI.

Every visual element must have a reason to exist.

Prioritize:

1. Information hierarchy
2. Usability
3. Visual identity
4. Consistency
5. Clarity
6. Professional polish
7. Responsive behavior

Do not add visual effects simply because they are fashionable.

---

# Avoid "AI Generated" Aesthetics

Do NOT automatically use:

- excessive rounded cards
- excessive pill-shaped elements
- excessive gradients
- glassmorphism everywhere
- giant headings
- excessive shadows
- floating cards everywhere
- decorative blobs
- random abstract backgrounds
- excessive icon usage
- excessive emojis
- generic SaaS layouts
- identical cards repeated across the page
- excessive whitespace with no purpose
- purple/blue gradient aesthetics
- unnecessary animations
- excessive borders
- excessive badges
- dashboard layouts made entirely from cards

Do not make every section look like a card.

Use different visual structures when appropriate.

---

# Professional Product Design

A professional interface should communicate hierarchy immediately.

For each page determine:

- What is the primary action?
- What information is most important?
- What information is secondary?
- What should the user notice first?
- What can be visually minimized?
- What actions should be grouped?
- What information should remain visible?
- What information belongs in a detail view?

Do not treat every piece of information with the same visual importance.

---

# Layout

Prefer intentional layouts over collections of cards.

Possible structures include:

- split layouts
- tables
- compact summaries
- timelines
- activity feeds
- operational panels
- side panels
- detail pages
- structured forms
- command/action areas
- maps
- tracking timelines
- status sections
- data-dense operational views

Use cards only when grouping information genuinely improves comprehension.

---

# Visual Hierarchy

Use typography, spacing, position and contrast to establish hierarchy.

A typical page should have:

1. Clear page title
2. Short contextual description when useful
3. Primary action
4. Main content
5. Secondary information
6. Supporting actions

Avoid unnecessarily large headings.

Prefer strong but controlled typography.

---

# Venexpress Brand

Venexpress visual identity is based on:

- Yellow
- Blue
- Red
- White
- Neutral dark/slate tones

The brand should feel:

- Venezuelan
- reliable
- fast
- modern
- operational
- trustworthy

Do not use the brand colors everywhere.

Use them strategically.

Yellow can communicate:

- action
- attention
- highlights
- important states

Blue can communicate:

- trust
- navigation
- primary actions
- information

Red should generally communicate:

- errors
- critical states
- warnings
- important brand accents

Neutral colors should provide most of the interface structure.

---

# Color Discipline

Do not create a page where yellow, blue and red compete equally.

Use a dominant neutral interface with controlled brand accents.

Example approach:

- neutral background
- dark text
- blue primary action
- yellow accent
- red only when semantically necessary

Do not use gradients between brand colors unless there is a very strong
design reason.

---

# Typography

Typography should feel deliberate.

Use:

- strong hierarchy
- readable body text
- controlled font sizes
- appropriate line height
- restrained font weights

Avoid:

- huge marketing-style headings in operational dashboards
- excessive bold text
- using multiple font families without reason
- making every label visually prominent

---

# Spacing

Spacing should establish relationships.

Related elements should be close.

Unrelated sections should have more separation.

Do not use large empty spaces simply to make a design appear modern.

Whitespace should support hierarchy.

---

# Venexpress Visual Direction

The current Venexpress interface should evolve from a generic modern SaaS
appearance into a distinctive logistics product.

The product must feel like a real Venezuelan logistics company with its own
visual language.

The design should NOT resemble:

- generic admin templates
- generic SaaS dashboards
- AI-generated Tailwind showcases
- startup landing page templates

---

# Current Design Problems To Avoid

Current interfaces may contain patterns such as:

- repeated metric cards
- excessive rounded containers
- large empty spaces
- centered hero layouts
- generic split-screen authentication pages
- isolated form cards
- excessive use of blue panels
- repeated icon badges
- decorative UI without operational purpose

These patterns should not automatically be repeated in new interfaces.

Existing components may be improved progressively rather than being blindly
recreated.

---

# Venexpress Design Personality

Venexpress should feel:

- fast
- operational
- reliable
- Venezuelan
- modern
- confident
- practical
- human

It should feel like software used by a real logistics company.

The interface should communicate movement, routes, packages, cities and
operations without relying on excessive illustrations or decorative effects.

---

# Logistics-Oriented Layouts

Prefer layouts inspired by real logistics operations.

Useful visual structures include:

- shipment timelines
- route progress
- operational tables
- delivery queues
- package status boards
- geographic information
- activity feeds
- compact KPI summaries
- action panels
- split detail views
- operational alerts
- tracking journeys

Do not force all information into cards.

---

generic SaaS dashboard.
